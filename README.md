# 📝 TODO List API (Go)

Простой REST-сервис **TODO-лист**, написанный на **Go**.

---

## 🚀 Возможности

✔ Создавать задачи  
✔ Получать задачу по названию  
✔ Получать все задачи  
✔ Фильтровать задачи по параметру `completed`  
✔ Отмечать задачу как выполненную  
✔ Удалять задачи  

---

## 🛠 Используемые технологии

- **Go**
- **net/http** — стандартный HTTP-сервер Go
- **github.com/gorilla/mux** — роутер для REST-маршрутов

---

## 🧱 Архитектура

Проект построен с чётким разделением слоёв:

- **business logic** — логика работы с задачами  
- **handlers** — HTTP-обработчики  
- **HTTP server** — маршрутизация и запуск сервера  

---

## 📌 API Endpoints

| Метод | Путь | Описание |
|------|------|----------|
| `POST` | `/tasks` | Создать задачу |
| `GET` | `/tasks/{title}` | Получить задачу по названию |
| `GET` | `/tasks` | Получить все задачи |
| `GET` | `/tasks?completed=true` | Получить только завершённые задачи |
| `PATCH` | `/tasks/{title}` | Отметить задачу как выполненную |
| `DELETE` | `/tasks` | Удалить задачу |
